# PageHeaderSkeleton

`packages/core/components/molecules/skeletons/PageHeaderSkeleton.js` · **Tier:** molecule (skeleton) · **Module:** core · **Rendering:** Server Component

## Purpose

A placeholder for the top of inner pages: a back-button block plus a title/subtitle
row and a trailing action.

## Props

None.

## Composition

- **Uses:** `atoms/core/Skeleton`.
- **Used by:** inner-page `loading.js` files.

## Accessibility

All `Skeleton` blocks are `aria-hidden`.
