# DetailHeaderSkeleton

`packages/core/components/molecules/skeletons/DetailHeaderSkeleton.js` · **Tier:** molecule (skeleton) · **Module:** core · **Rendering:** Server Component

## Purpose

A banner placeholder for detail pages: a tall image area, title, subtitle, a meta
chip row and a couple of action buttons.

## Props

None.

## Composition

- **Uses:** `atoms/core/Skeleton`.
- **Used by:** detail-page `loading.js` files (events, spaces, routes, places).

## Accessibility

All `Skeleton` blocks are `aria-hidden`.
